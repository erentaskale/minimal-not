# Minimal Not

Karanlık temalı, dikkat dağıtmayan, minimalist bir not alma uygulaması.

Sayfa açılır, imleç hazırdır, yazmaya başlarsın. Notunu `.txt` veya `.md` olarak kaydedebilirsin.

## Kullanım

Kurulum gerekmez. `index.html` dosyasını tarayıcıda açman yeterli.

## Teknolojiler

- HTML
- CSS
- JavaScript
