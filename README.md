# Minimal Not

Dikkat dağıtmayan, minimalist bir not alma uygulaması.

Sayfa açılır, imleç hazırdır, yazmaya başlarsın. Yazarken menü kaybolur, durunca geri gelir. Notunu `.txt` veya `.md` olarak indirebilirsin.

## Özellikler

- Karanlık ve aydınlık tema
- Odak modu: yazarken menü ve sayaç gizlenir
- Otomatik kayıt: sayfayı kapatsan da notun tarayıcıda kalır
- Kelime ve karakter sayacı
- Klavye sesi: her tuşta yumuşak bir mekanik klavye tıkı (menüden kapatılabilir)
- `.txt` / `.md` olarak indirme (ilk satır dosya adı olur)
- Yazı boyutu ayarı; tema ve yazı boyutu tercihi hatırlanır
- Telefonda da çalışır

## Klavye kısayolları

| Kısayol | İşlev |
|---|---|
| `Ctrl` + `S` | `.md` olarak indir |
| `Ctrl` + `Shift` + `S` | `.txt` olarak indir |
| `Ctrl` + `+` / `-` | Yazıyı büyüt / küçült |
| `Ctrl` + `0` | Yazı boyutunu sıfırla |
| `Tab` | Girinti ekle |

## Kullanım

Kurulum gerekmez. `index.html` dosyasını tarayıcıda açman yeterli.
